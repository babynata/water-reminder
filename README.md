# Water Reminder 💧

智能交互式喝水提醒系统，基于 OpenClaw 微信通道推送，支持个性化定制、动态进度追踪和用户反馈闭环。

## Features

- 🎯 **个性化咨询**：根据用户背景、目标、条件定制专属喝水计划
- 📊 **实时进度追踪**：每条消息带视觉进度条，清晰感知今日饮水量
- 💬 **交互式反馈**：中午/傍晚主动询问饮水量，动态调整后续提醒
- 🌙 **睡前总结**：每日达成率、分段记录、明日建议
- 📱 **微信推送**：基于 openclaw-weixin 通道，cron 定时自动送达

## Quick Start

### 1. 创建喝水提醒
对 OpenClaw 助手说：
```
帮我设置喝水提醒
```

助手会进入咨询流程，确认：
- 喝水背景（习惯、特殊情况）
- 日目标（ml 或杯数）
- 提醒时间偏好
- 推送渠道（默认微信）

### 2. 每日交互

| 时间 | 动作 |
|------|------|
| 09:00 | 第1杯 500ml |
| **12:00** | **检查：回复上午喝了多少** |
| 13:00 | 第2杯（根据12:00反馈动态调整）|
| **18:00** | **检查：回复下午喝了多少** |
| 21:00 | 第3杯（动态调整剩余量）|
| 22:30 | **睡前总结** |

回复数字（如 `300`）即可记录饮水量。

### 3. 管理提醒

```
停止喝水提醒      → 暂停所有定时任务
调整喝水计划     → 重新进入咨询流程
查看喝水进度     → 显示当前状态和进度
```

## Project Structure

```
wechat-water-reminder/
├── SKILL.md                          # Skill 定义 + 工作流
└── scripts/
    └── water_tracker.py              # 状态管理 + 动态消息生成
```

### water_tracker.py 命令

| 命令 | 作用 |
|------|------|
| `init` | 重置当日状态 |
| `record AMOUNT` | 记录用户回复的饮水量 |
| `status` | 查看当前状态 JSON |
| `message HH:MM` | 生成对应时间的提醒消息 |
